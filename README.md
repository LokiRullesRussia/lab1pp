# Лабораторная работа №1. 

##  Описание

Первая лабораторная работа посвящена изучению базовых конструкций языка Go:
объявлению переменных, работе с типами данных, арифметическим операциям,
функциям и вычислениям.

## 🎯 Цель работы

- Познакомиться с синтаксисом языка Go.
- Научиться объявлять переменные различными способами.
- Освоить арифметические операции и написание простых функций.
- Получить навыки работы с датой и временем через пакет `time`.

## ✅ Задания

1. **Текущее время и дата.**
   Написать программу, которая выводит текущее время и дату.

2. **Переменные различных типов.**
   Создать переменные типов `int`, `float64`, `string`, `bool` и вывести их на экран.

3. **Краткая форма объявления.**
   Использовать краткую форму объявления переменных (`:=`) для создания и вывода переменных.

4. **Арифметические операции.**
   Написать программу для выполнения арифметических операций (`+`, `-`, `*`, `/`, `%`)
   с двумя целыми числами и выводом результатов.

5. **Функция суммы и разности.**
   Реализовать функцию для вычисления суммы и разности двух чисел
   с плавающей запятой.

6. **Среднее значение.**
   Написать программу, которая вычисляет среднее значение трёх чисел.
